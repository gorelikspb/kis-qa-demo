Willkommen

Dies ist eine Demo-Anwendung für QA-Demonstration.

📦 Quellcode auf GitHub: github.com/gorelikspb/kis-qa-demo
Vollständiger Code, Tests und Dokumentation verfügbar

🚀 Live Demo: kis-qa-demo.up.railway.app
Diese Anwendung läuft live auf Railway

Verfügbare Funktionen:

  • Patient anlegen - Erstellen Sie einen neuen Patienten mit Name, Geburtsdatum und Versicherungsnummer
  • Termin erfassen - Erfassen Sie einen Termin mit Datum, Uhrzeit, Arzt und Status
  • Patienten - Zeigen Sie alle angelegten Patienten
  • Termine - Zeigen Sie alle erfassten Termine
🧪 Testfälle zum Ausprobieren (klicken zum Aufklappen)
+ 🎁 Bonus-Testfall für ⭐ QA Master ⭐!

Alle 19 Testfälle auf GitHub

Patient anlegen - Testfälle:

  1. Pflichtfeld-Validierung: Lassen Sie das Feld "Name" leer und versuchen Sie zu speichern → Fehlermeldung sollte erscheinen
  2. Datum-Format: Geben Sie ein Datum im falschen Format ein (z.B. "1990-03-15") → Fehlermeldung sollte erscheinen
  3. Versicherungsnummer: Geben Sie eine Versicherungsnummer mit weniger als 10 Ziffern ein → Fehlermeldung sollte erscheinen
  4. Erfolgreiche Speicherung: Füllen Sie alle Felder korrekt aus:
    • Name: "Max Mustermann"
    • Geburtsdatum: "15.03.1990"
    • Versicherungsnummer: "1234567890"
    → Erfolgsmeldung sollte erscheinen, Patient sollte in der Liste sein

Termin erfassen - Testfälle:

  1. Pflichtfelder: Lassen Sie verschiedene Pflichtfelder leer → Fehlermeldungen sollten erscheinen
  2. Uhrzeit-Format: Geben Sie eine Uhrzeit im falschen Format ein (z.B. "14:30:00") → Fehlermeldung sollte erscheinen
  3. Erfolgreiche Speicherung: Füllen Sie alle Felder korrekt aus → Erfolgsmeldung sollte erscheinen

🎁 Bonus: Finden Sie den versteckten Testfall!

Es gibt einen speziellen Testfall, der nicht in der Standard-Dokumentation steht. Wenn Sie ihn finden und erfolgreich durchführen, erhalten Sie einen ⭐ Stern als Belohnung!

Hinweis: Schauen Sie genau hin - manchmal sind die interessantesten Bugs die, die man nicht erwartet...

📋 Beispiel-Testfälle (aus der Dokumentation):

TC-PAT-001: Pflichtfeld Name leer

Priorität: Hoch

Schritte:

  1. Seite "Patient anlegen" öffnen
  2. Feld "Name" leer lassen
  3. Geburtsdatum (z.B. "15.03.1990") und Versicherungsnummer (z.B. "1234567890") ausfüllen
  4. Auf "Patient speichern" klicken

Erwartetes Ergebnis: Fehlermeldung: "Name ist ein Pflichtfeld"

Tatsächliches Ergebnis: ✅ Fehlermeldung wird angezeigt

TC-PAT-004: Ungültiges Datumsformat

Priorität: Mittel

Schritte:

  1. Seite "Patient anlegen" öffnen
  2. Name eingeben: "Max Mustermann"
  3. Geburtsdatum eingeben: "1990-03-15" (falsches Format)
  4. Versicherungsnummer eingeben: "1234567890"
  5. Auf "Patient speichern" klicken

Erwartetes Ergebnis: Fehlermeldung: "Geburtsdatum muss im Format DD.MM.YYYY sein (z.B. 15.03.1990)"

Tatsächliches Ergebnis: ✅ Fehlermeldung wird angezeigt

  • Fehlermeldungen bei ungültigen Eingaben
  • Erfolgreiche Speicherung bei korrekten Daten
